# wallet-mcp-server

Local MCP server a user installs into their agent (Claude Desktop or any
other MCP client) to consume the PolyPay catalog with x402 auto-payment
over XRPL, without writing any code.

Work in progress — see `PLAN.md` for the full architecture. The
installation section (config block, environment variables, security
warning about the wallet seed) gets documented here once the package is
ready to publish (Phase 3 of the plan).
